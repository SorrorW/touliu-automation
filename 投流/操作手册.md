# 投流操作台 操作手册

> 一看就懂版。不用懂技术，照着点就行。

---

## 一、怎么打开

**平时用**：双击桌面上的「投流操作台」图标（蓝底白色「投」字），等几秒窗口就出来了。

**第一次用（新电脑）**：

1. 电脑需装有 Microsoft Edge（Win10/11 一般自带）。
2. 把「投流」文件夹从 zip 解压出来（放哪都行，比如 D 盘）。
3. 双击文件夹里的「启动UI.bat」——窗口会打开，桌面上也会**自动出现**「投流操作台」图标，以后都从桌面图标启动。
4. 首次打开会拉起一个专用的 Edge 窗口，在浏览器里扫码登录千川（登录一次，以后保持；过期了重新扫码即可）。这个 Edge 窗口是自动化专用的，和你平时上网的 Edge 互不影响。

- 点图标没反应？→ 找技术人员看 `投流/webui/assets/desktop_error.log`。
- 窗口左上角红点「未连接」？→ 去「会话/任务」页点「切换到 业务1部」；
  还不行就在自动化专用的 Edge 窗口里登录千川后再试。

界面左边导航分三组：「抖音」下 4 个页面、「视频号」下 1 个页面、「系统」下 2 个页面，共 7 个页面，下面逐个说。

## 二、监控扫描（每天用得最多）

**干什么用**：一次把三个部门的所有计划数据拉回来，谁达标、谁没出单一目了然。

**怎么用**：

1. 部门选「全部部门」（也可以只看某一个部门），点 **开始扫描**。
2. 等 2-3 分钟（右下角有任务条提示，这期间别去动千川网页）。
3. 结果按部门分表格展示，按钮旁边会显示「上次扫描: 时间」——
   **关掉再打开数据也还在**，不怕误关。

**筛选（扫描按钮右边四段）**：

- **全部**：所有计划
- **只达标**：只看达标计划（ROI ≥ 11 且 成交 ≥ 5，绿色显示）
- **仅有数据**：今天有消耗或成交的
- **无数据**：今天没消耗没成交的（找出不出单的达人就靠它）

**排序**：点表头「消耗(元) / 综合ROI / 成交订单」就能排：
点一下从大到小 ↓，再点从小到大 ↑，再点回到原来的顺序。

**一键追投**：每行后面都有。点一下、确认一次就完成（固定 100 元/24 小时），
不用再做别的操作。达标（绿色）的行当天优先追。

## 三、建计划

**干什么用**：新建投放计划，自动完成 授权 → 建计划 → 建追投 三步。

**怎么用**：

1. 按格子填：部门（下拉选）、业务员、抖音号 ID、合作码（授权没生效才要填）、
   商品（下拉选，选不到就选「自定义商品ID」手输）。
2. 达人名、ROI（默认 7.3）、日预算（默认 300）可不填。
3. **「直接发布」开关默认关**：关着 = 只建好不上线；打开 = 立即上线烧钱，
   打开前再核对一遍。
4. 点 **确认执行**，下面会出现三步进度，全绿勾就成功了；有红叉就截图找技术。

**懒得填？** 点「粘贴文本自动填写 ▾」，把任务文本粘进去点「解析并填入」，
AI 会自动填到格子里（首次用要先在顶部配置 API：选 DeepSeek 或 Kimi，填 Key，保存，
可以点「测试连接」确认能用）。

**右侧「待建计划」面板**：授权没走完、计划没上线的达人会留在这里，每条都显示
授权状态和「授权查询于 时间」。

- **重新查询授权**：刷新该达人的授权状态（达人确认后点它）。
- **重新申请授权**：达人超过 24 小时没确认、申请失效了点它，会用原来的合作码重新提交。
- **发布计划+追投**：授权生效后点它，一键把计划建完上线。

## 四、重点关注

**干什么用**：盯住几个重点老达人，系统按规则判断该不该追投。

**规则**（页面顶部也写着）：近七天单量 < 7 为低效 → 追投 100 元/24 小时；
最多追 2 次还低效就自动休息 7 天。

**怎么用**：

- **刷新评估**：点一下更新数据（只判断，不会自动追投）。
  平时打开页面看到的就是上次的结果，旁边有「上次评估: 时间」。
- 表格里能直接看到每个达人的**近七天单量、消耗（元）、综合ROI**（近 7 天汇总）。
- **符合（绿色）** → 点行内「一键追投」。
- **不符合（红色）** → 看旁边原因：单量达标 = 不用管；追投中/休息期 = 等它结束。
- **添加关注**：填达人名 + 部门，点「添加关注」。
- **移除**：不想关注了就点，删了就真的删了（文件同步），想清楚再点。

## 五、授权管理

**干什么用**：查达人授权有没有生效、提交授权申请。

- **查状态**：填抖音号 ID 选部门，点「检查」。
  绿色 = 已生效；红色 = 未生效。
- **申请**：填抖音号 ID + 合作码，点「提交授权」。
  提交后要通知达人 **24 小时内**在抖音 APP 站内信里确认，否则不生效。

## 六、视频号投流下单

**干什么用**：给微信视频号小店的视频下加热订单。脚本自动选视频、填表单、勾协议，但**不会点提交**——必须在浏览器里人工核对后手动提交。

**怎么用**：

1. 先点 **打开视频号会话** 拉起 Edge 打开视频号小店推广页；没登录就在浏览器里扫码登录。
2. 填表单：
   - **作者关键词（可选）**：填了会搜指定作者的视频；留空用默认作者视频。
   - **视频筛选日期（可选）**：按日期筛视频。
   - **优先提升目标**：默认「商品ROI」（选不到可自定义，输入与后台完全一致的名字）。
   - **出价方式**：默认「控成本加热」（也有「放量加热」或自定义）。
   - **ROI 目标**：默认 7.3。
   - **加热时长**：默认 24 小时（可选 6/12/24/48/72）。
   - **订单预算**：默认 300 元；勾「跳过」则不填、让页面自动带出。
   - **人群模版**：默认「肥牛片」（也有「非肥牛片」或自定义）；勾「跳过」则不使用模版。
3. 点 **填表并勾协议（不提交）**——脚本会自动选视频、填表、勾协议，停在提交前。
4. 到浏览器里人工核对无误后，**手动点「提交」**。

## 七、会话/任务 与 系统日志（技术人员常用）

- **浏览器会话**：显示连接状态，三个按钮切换部门账号。
- **最近任务**：最近 7 天跑过的任务（扫描、追投、建计划、视频号下单），重启也在。
  任务自动排队：同时提交多个任务时先提交的先跑，后面的显示「排队中」，
  不会互相抢浏览器。点错任务可在该行点「终止」（执行中的任务被终止后，
  千川网页可能停在中间状态，属正常）。
- **系统日志**（独立页面）：抖音、视频号任务和系统事件的运行日志都记录在此，
  技术排查用，可选行数、可下载（出问题时把这个文件发给技术）。

## 八、常见问题

| 问题 | 怎么办 |
|---|---|
| 点图标打不开 | 把 `投流/webui/assets/desktop_error.log` 发给技术 |
| 一直「未连接」 | 打开 Edge 登录千川 → 会话/任务页切一次部门 |
| 扫描卡住不动 | 看看是不是有人在动千川网页；等任务条结束再操作 |
| 按钮点了没反应 | 看右下角任务条是不是还有任务在跑，跑完再点 |
| 误关窗口 | 直接重新双击图标，扫描和评估数据都在，带时间戳 |
