# 投流系统 - 消息格式规范

> 团队按此格式发消息，系统自动解析执行。

---

## 抖音巨量千川

一行一条，空格分隔，固定顺序：

```text
抖音 <抖音号> <达人名称> <合作码> <商品id> <业务员> <业务部>
```

| # | 字段 | 示例 | 必填 | 说明 |
|---|------|------|------|------|
| 1 | 抖音号 | `20161121Z` | ✅ | 达人抖音号 |
| 2 | 达人名称 | `煮妇小承妈` | ✅ | 用于计划名 |
| 3 | 合作码 | `96840444931` | ✅ | 授权用，仅首次需要 |
| 4 | 商品id | `3625226808611490412` | ✅ | 千川商品ID |
| 5 | 业务员 | `赵` | ✅ | 用于计划名 `MMDD_达人_姓` |
| 6 | 业务部 | `3` | ✅ | 1 / 2 / 3 |

**自动执行流程：**

```
授权检查 → (如需)授权达人 → 建投放计划 → 建追投(预算100/24h)
```

---

## 视频号投流

```text
视频号 <达人名称> <商品> <视频时间>
```

| # | 字段 | 示例 | 必填 | 说明 |
|---|------|------|------|------|
| 1 | 达人名称 | `我家厨房1688` | ✅ | 用于搜索作者视频 |
| 2 | 商品 | `肥牛片` | ✅ | 对应人群模版 |
| 3 | 视频时间 | `7月20号` | ✅ | 筛选视频发布日期 |

**自动执行流程：**

```
打开视频号后台 → 选视频 → 填ROI/预算 → 停留待提交
```
