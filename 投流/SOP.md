# 投流操作 SOP（标准作业流程）

> 适用对象：投流操作人员。工具：投流操作台（桌面「投流操作台」图标）。
> 配套文档：《投流操作台操作手册》。
> 版本：v2.3（2026-10）。

---

## 0. 企微智能表格进度字段（业务员每日必看）

订单表「进度」列由系统自动维护，各状态含义和业务员要做的事：

| 进度 | 含义 | 业务员动作 |
|---|---|---|
| 可投放 | 排队等系统处理（授权→旧计划处理→建计划） | 无，等系统跑（建计划只在 23:00–07:59 夜间窗口） |
| 已投放 | 计划已在投（含系统新建、收养老计划起投） | 无 |
| 达人未确认授权 | 授权已提交，等达人在抖音 APP 站内信确认（系统每 30 分钟复查） | 催达人点确认 |
| 没有挂车视频 | 达人**从没发过**该商品的挂车视频 | 联系达人发挂车视频，发后把进度改回「可投放」 |
| 待业务员补新素材 | 达人发过挂车视频，但全部超过 72 小时 | 联系达人发新视频，发后把进度改回「可投放」 |
| 达人无推广权限 | 平台明确无短视频带货权限 | 达人去抖音申请开通，或关票 |
| 待业务员核查 | 建计划被平台禁用但原因读不出（多为已有重复计划或权限问题） | 报技术核查，不要反复改回「可投放」 |
| 佣金过高 | 佣金率 >5%，不投 | 与达人谈到 ≤5%（次日生效）后改回「可投放」 |
| 合作码错误 | 合作码校验不过 | 向达人重新要码更新后改回「可投放」 |
| 商品ID无效 | 商品 ID 查不到 | 核对后更新 |

注意：「没有挂车视频」和「待业务员补新素材」是两回事——前者达人根本没发过该商品视频，
后者是发过的视频都过期了。两类都需要达人动作后**人工把进度改回「可投放」**才会复活，
系统不会自己复查这两类。

## 1. 每日节奏（系统自动为主）

- **23:00–07:59**：系统自动处理「可投放」票（授权→旧计划处理→建计划），建成的计划先暂停。
- **08:00 恢复槽**：夜间建成的计划统一起投。
- **白天**：系统只做监控/启停/授权复查，不新建计划；白天急需补建找技术人员开临时窗口。
- **开机**：轮询后端和操作台已设开机自启，正常无需手动拉起；自启异常再按第 2 节处理。
- **老达人发新视频**：有计划的一律走「老计划新素材」（系统给老计划加素材起投），**不删老计划**。

## 2. 上午：建立计划（按需）

有新达人/新计划任务时，在「建计划」页操作：

1. 按模板填空：部门、业务员、抖音号、合作码（授权未生效时必填）、商品。
2. 「直接发布」开关**默认保持关闭**；只有确认要立即上线时才打开。
3. 点「确认执行」，等待 授权 → 建投放计划 → 建追投 三步完成。
4. 时间线任一步变红 → 截图发给技术人员，不要重复点。

## 3. 白天：监控扫描（建议 11:00 / 15:00 / 19:00 各一次）

1. 「监控扫描」页，部门选「全部部门」，点「开始扫描」（约 2-3 分钟，期间不要动千川页面）。
2. 扫完先看三部门汇总卡，再按需要用筛选和排序定位计划：

| 要找什么 | 操作 |
|---|---|
| 高出单计划 | 筛选「只达标」，或点「成交订单」降序 |
| 消耗异常高的 | 点「消耗(元)」降序 |
| ROI 好的 | 点「综合ROI」降序 |
| 今天没出单的 | 筛选「无数据」 |

3. **达标计划（ROI ≥ 11 且 成交 ≥ 5，绿色行）**：当天直接点行内「一键追投」放大流量。
4. 其他需要人工干预的计划：也可用行内「一键追投」（固定 100 元/24 小时）。

## 4. 重点关注达人（每天下午评估一次）

1. 「重点关注」页点「刷新评估」（只判断不追投）。
2. 显示「符合」的 → 点「一键追投」（规则：近七天单量 < 7 才追，最多 2 次，仍低效自动休息 7 天）。
3. 显示「不符合」的看原因：单量达标（好事，不用管）/ 追投中 / 休息期（等自动结束）。
4. 不再关注的达人点「移除」（同步删文件，常驻）。

## 5. 授权类问题

- 建计划提示授权未生效 → 到「授权管理」页查状态；
  有合作码就提交授权申请，并通知达人 24 小时内在抖音 APP 站内信确认。

## 6. 视频号投流（按需）

1. 有视频号加热任务时，到「视频号投流」页操作。
2. 点「打开视频号会话」登录视频号小店推广页。
3. 填表单（作者关键词、日期、目标、出价、ROI、预算、时长、模版），点「填表并勾协议（不提交）」。
4. **脚本只填表不提交**——必须在浏览器人工核对后手动点提交。

## 7. 安全红线（必须遵守）

1. 「直接发布」开关：不确认不上线，打开前必须再核对一遍部门和预算。
2. 「移除」「删除追投」类操作不可恢复，确认弹窗出现时必须看清对象再点。
3. 任务运行中（右下角任务条转圈）**不要手动操作千川页面**，会互相干扰。
4. 界面只能本机使用，不要把 8321 端口暴露给其他人。
5. **不删老计划**：有存量计划的达人一律走老计划新素材；删除计划不可逆，任何删除必须先经主管确认。
6. 企微白名单表的启用/停用是主管操作入口，系统和业务员都不动；白名单计划系统绝不自动启停。

## 8. 异常上报（给技术人员的信息）

遇到问题发这三样给技术人员：

1. 问题截图（含页面和时间）。
2. 「系统日志」页 → 「下载」得到的 webui.log。
3. 如果是启动失败：`投流/webui/assets/desktop_error.log` 文件。
