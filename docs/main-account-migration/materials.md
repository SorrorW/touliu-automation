# 主号抖音号与视频素材闭环

主表、旧素材表均先按商品ID核验对应主品计划是否已绑定达人。未绑定才走主号合作达人授权和加入抖音号。加入抖音号时取消“含达人佣金出价”，保存前后复核其他字段不变，避免现有ROI保存限制阻塞。

绑定后必须独立核验视频素材：

1. 打开正确主品计划的“素材”。
2. 点击“添加视频”，选择“自动拉取的抖音号”。
3. 用表格“抖音号”精确搜索并选中达人；不以达人昵称或其他数字列代替。
4. 完整读取该达人针对当前商品的视频及本计划在用状态。已有视频时直接复核，不重复添加。
5. 未加入任何视频时，按实际创建时间选择最新可用且佣金合规的视频，提交“确定”。本流程不套用分部建计划的72小时素材门槛。
6. 重新进入计划读取，确认所选视频已在本计划内，才写“主号已拉取”或“主号已加入”。

暂时没有视频、分页不完整、选择器未明确、保存结果未知时均保留断点，不把达人绑定等同于素材完成。表格进度使用“待加入素材”；后续轮询先复核，避免提交成功但响应丢失时重复添加。

例：小北大的麻麻，抖音号`Xiaobeida`；肥牛主品`3625226808611490412`，目标计划`1839594740761991`。

流程版本为`main-products-v2-materials`。旧版本绑定成功、回写待同步断点不能充当新版素材完成凭据。台账保存账号、抖音号、商品、计划、视频ID、作品ID、复核时间与结果，不保存合作码或视频签名地址。


## 扫描与重试保护

主品达人列表分页只点击实际下一页，排除页码省略号。读取条数必须与平台总数一致，分页未完成时不得认定未绑定。达人搜索只在自动拉取的抖音号下拉结果内匹配精确ID，避免选中计划明细中同名ID。搜索回车可能提前触发素材请求，核验覆盖搜索开始后的响应。

手动重试保留明确停投要求，按表格昵称和抖音号共同检查。待人工记录遇到扫描异常时保留原处理状态及异常原因，不把扫描失败当成缺少授权。

离线浏览器回归可设置 `TOULIU_UI_FIXTURE_TESTS=1`，运行 `python -m unittest discover -s wecom-agent -p test_main_ui_locators.py`。测试只启动独立无头Edge和本地HTML，不连接业务浏览器。


作者身份同时读取自动拉取列表接口和现有计划的 `get_ad_aweme_list` 响应。后者可能是已绑定达人内部作者ID的唯一来源；漏读时会出现页面能搜到精确抖音号、程序却报作者ID未核实的情况。新增来源仍按精确公开抖音号匹配唯一内部作者ID；视频和在用状态继续分别校验账号、商品、作者及计划，不根据昵称猜测身份。

手动授权加入的达人可能使用独立视频标签，不出现在自动拉取下拉框。先由当前接口中的精确抖音号确认唯一作者UID，再定位唯一视频标签；同名多个入口或作者ID冲突时中止。标签点击只读取素材，后续视频响应仍必须同时匹配主号、商品及已核实作者UID，计划在用状态仍校验目标计划，不以昵称证明素材归属。素材提交前固定选择抽屉节点，避免关闭后 `:visible.last` 转向外层抽屉而误报超时；提交后仍重新导航验证保存结果。

切换手动达人视频标签前，等待上一视频来源的读取结束并稳定，避免默认来源的迟到响应把分页游标带入新作者查询；请求未结束时保留待处理，不用空页判定视频消失。读取失败或取消均释放监听。
