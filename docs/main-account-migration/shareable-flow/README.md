## 可编辑流程

```mermaid
flowchart TD
    A[业务填主表或旧素材表<br/>达人账号、合作码、商品ID、投放日期] --> B{四主品、资料有效<br/>且无明确人工停投？}
    B -->|不符合| M[待人工处理<br/>保留具体原因]
    B -->|符合| C[核对主号、商品与计划<br/>读取完整绑定名单]
    C -->|读取失败或分页不完整| X[暂挂复查<br/>不将未知当作未绑定]
    C --> D{对应主品已有有效绑定？}
    D -->|已有| K[自动拉取：主号已拉取<br/>手动绑定：主号已加入]
    D -->|未绑定或已删除| E{佣金是否超过上限？}
    E -->|超过| R[佣金过高<br/>调整后复查]
    E -->|未超过| F[主号核验两项权限<br/>抖音号授权＋商品投放授权]
    F --> G{两项均已生效？}
    G -->|待确认| W[等待达人接受<br/>保存断点、释放浏览器]
    W -.->|后续轮询核验| C
    G -->|已生效| H{已到预约投放日？}
    H -->|未到| Q[待加入主品<br/>到期后重新核验]
    Q -.->|到期复查| C
    H -->|已到| I[提交前再查绑定<br/>防止授权等待期间已自动拉取]
    I -->|已经绑定| K
    I -->|仍未绑定| J[添加到对应既有主品计划<br/>保存后完整复核]
    J -->|确认有效绑定| K
    J -->|结果不明| T[保留断点和原因<br/>下轮先查实际绑定再重试]
    T -.-> C
    J -->|平台明确拦截| M
    K --> L[同步绑定快照、数据库和表格<br/>读回一致后闭环]
    L -->|表格回写失败| S[仅补表格同步<br/>不重复授权或添加]
    S -.-> L
```

## 需要对齐的规则

- 当前佣金上限为5%，等于5%允许继续；实际阈值由本机配置决定。
- 同达人、同主品跨表只操作一次，关联记录分别回写；同达人多个主品分别处理。
- 已有效绑定直接同步完成；历史分部已投放或已完成记录不自动重新接管。
- 等待达人接受、待加入主品是中间状态；真实新增成功必须确认对应主品内的有效绑定。
- 系统需要桌面及自动化保持开启。等待确认时保存断点并释放浏览器，随轮询接续处理。
- 本流程仅处理达人授权与加入主品计划；主品计划ROI、预算及启停参数保持原值，原分部日报和收口沿原规则执行。
