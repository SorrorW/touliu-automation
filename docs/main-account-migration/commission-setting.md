# 主号添加抖音号时的佣金开关

向四个现有主品计划添加抖音号时，保存前取消“含达人佣金出价”。仅允许变更这一选项；ROI、预算、名称及其他输入和开关必须保持原值。

精确定位佣金文案及关联的复选框。新版卡片的文案嵌套较深，仍需定位实际 checkbox，不能从整页取第一个开关。已关闭时不反向勾选；控件不唯一、取消未生效或其他参数发生变化时禁止保存。

添加抖音号后、提交保存前再检查一次；保存后重新打开计划，复核佣金关闭且其他参数不变。已经绑定的达人仍直接返回绑定结果，不单独重存计划。

验证覆盖目标选项取消、原本关闭、取消失败及其他字段变化。2026-10-20临时编辑页实测取消后ROI40、预算1000和名称保持原值；未借此测试保存计划。


既有主品的抖音号管理入口使用精确可见文案“管理手动添加抖音号”（或对应添加入口），点击后必须出现唯一可见达人搜索框才继续。该入口使用元素点击以避开页面会重新出现的第三方插件遮罩；多个入口或搜索框一律中止，不采用全页模糊按钮回退。分部建计划的入口不受此变更影响。

平台确认新达人后可能自动重新勾选“含达人佣金出价”。因此抽屉确认前和保存前均执行取消及其他参数不变校验，保存后重开复核；不能仅在打开编辑器时取消一次。
